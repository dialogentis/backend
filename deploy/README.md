# Развёртывание API для Sites

Образ строится из каталога backend: `docker build -t atlas-backend .`.
Запускайте с постоянным томом `/data` и переменной окружения `ATLAS_API_TOKEN`, содержащей случайный секрет. Например, передавайте значения через защищённые настройки хостинга. Образ содержит Python 3.14 для API и Python 3.10 для изолированной Rasa.

Контейнер слушает 8000. Хостинг должен предоставить HTTPS и достаточно памяти для TensorFlow; рекомендуется начать с 4 ГБ RAM. Не публикуйте API без ATLAS_API_TOKEN. Первая база пустая; агентов можно создать в интерфейсе или добавить командой `/app/.venv/bin/python demo.py` внутри контейнера. Перенос existing data выполняется отдельно с обновлением model_path в SQLite.

После появления HTTPS-адреса настройте в Sites секреты BACKEND_URL и BACKEND_TOKEN. Последний должен совпадать с ATLAS_API_TOKEN. Браузер не получает секрет: Sites отправляет его серверу в Authorization. Доступ к самому Sites остаётся закрытым для посторонних.

Rasa 3.6.21 содержит известные уязвимости зависимостей; ограничения описаны в docs/AUDIT.md. Этот образ не объявляется решением этих уязвимостей.
