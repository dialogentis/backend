# Фиксированные наборы NLU

`fixtures.json` зафиксирован до первого запуска и настройки модели коммитом `1beb691`. В каждом наборе пять намерений, по 10 обучающих и 5 отдельных тестовых фраз на намерение, а также 20 неизвестных тестовых фраз. Идентификаторы получаются детерминированно из текста и кода агента. Валидация запрещает дубликаты между train и test. Тестовые фразы не используются при обучении.

Воспроизведение из корня backend:

```sh
uv sync --locked
uv run python benchmarks/nlu/evaluate.py
```

`baseline.json` — первоначальный результат с зафиксированными исходными порогами 0,55 / 0,15 / 0,20, хешами набора и `uv.lock`, версиями библиотек и платформой. В исходном прогоне intent macro F1 составил 0,00 для магазина и 0,15 для образовательного центра; доля отказов на известных запросах — 100% и 88%. Цель AC-05 для намерений не выполнена. Отказ на неизвестных — 100% в обоих случаях. Эти цифры относятся только к приведённым фразам и не являются оценкой качества на пользовательских данных.

Метрика сущностей получена на словарных сущностях: тестовая разметка формируется по тем же значениям словаря, а не независимыми аннотаторами. В тесте всего 3 и 7 размеченных вхождений соответственно, поэтому F1 1,0 здесь не доказывает качество обучаемого извлечения сущностей. Нужны независимая разметка и дополнительная проверка CRF.

Скрипт напрямую использует NLUAdapter; создание ready-версий через API и выполнение остальных условий AC-05 ещё требуют отдельной проверки. При изменении алгоритма не корректировать тестовые фразы по результатам прогона; настраивать параметры только на обучающей части и сохранять новый отчёт с указанием изменений.

Для диагностики регуляризации отдельно выполнена кросс-валидация исключительно обучающих фраз:

```sh
uv run python -m benchmarks.nlu.cross_validate
```

Результат сохранён в `cross_validation.json`: пять стратифицированных разбиений проверяют известные намерения, а поочерёдное исключение одного намерения приближённо проверяет отказ на незнакомом классе. Последнее не заменяет независимые неизвестные запросы. При исходном `C=1` все 50 проверочных фраз каждого набора получили отказ. При `C=10` верно распознаны 28/50 и 24/50 известных фраз, но отклонены только 39/50 и 36/50 фраз исключённых намерений. Ни один проверенный вариант не подтверждает одновременно необходимое распознавание и надёжный отказ, поэтому модель не перенастроена на основании этого опыта.
