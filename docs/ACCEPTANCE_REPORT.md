# Приёмка первого выпуска Dialogentis

Приёмка S15 продолжается. В журнале этапов сохранены результаты прогонов и найденные ограничения. Все команды для локальной проверки выполняются на отдельном Compose-проекте с отдельными томами PostgreSQL, RabbitMQ, Mailpit и артефактов.

## Воспроизведение

- Сервер и контракт. Из backend запустите `make integration`. Для вспомогательных проверок используются `uv run --locked ruff check`, `uv run --locked ty check` и генерация OpenAPI из `scripts/export_openapi.py`. Команды CI описаны в [.github/workflows/backend.yml](../.github/workflows/backend.yml).
- Кабинет и контракт клиента. Из frontend запустите `npm ci`, `npm run typecheck`, `npm run test:unit`, `npm run build` и `npm run api:generate`. Сценарии Chrome с реальной базой и очередью описаны в [инструкции frontend](../../frontend/README.md#проверки).
- Развёртывание, резервное копирование и восстановление. Используйте [инструкцию эксплуатации](OPERATIONS.md) и раздел Production в [README](../README.md#production).
- Производительность и обучение. Команды и форматы результатов описаны в [нагрузочном сценарии](../benchmarks/runtime/README.md) и [сценарии проверки качества](../benchmarks/nlu/README.md#демонстрационные-агенты-выпуска).

До изменений процесса выполнения диалога в Linux Compose прошли 359 серверных тестов. После изменения прошли 27 целевых тестов, включающих обработку ходов, подпись модели, изоляцию, тайм-ауты, приватность, передачу и публикацию. Повторный полный прогон ожидается. Результаты браузерной проверки до изменения приведены в [журнале S15](IMPLEMENTATION_STATUS.md#s15--приёмка-и-производительность-в-работе).

## Сценарии AC-01–AC-14

- **AC-01. Регистрация и пространства — пройден.** В Chrome пройдены регистрация, подтверждение письма из Mailpit, создание пространства, приглашение и переключение между организациями. Автоматическая серверная проверка подтверждает одноразовость ссылки восстановления и отзыв старой сессии. [Браузерный сценарий](../../frontend/scripts/smoke.mjs), [тесты авторизации](../tests/test_auth.py).
- **AC-02. Роли и изоляция — частично подтверждён.** Проверены матрица API, отзыв прав, изоляция списков и приватных ресурсов и SQL под app-role с отсутствующим и чужим tenant context. Chrome подтвердил приглашение, отказ редактору в управлении участниками и действия владельца. Для полной приёмки нужно отдельно зафиксировать положительные и запрещённые операции каждой роли в UI. [RLS](../tests/test_tenancy.py), [авторизация](../tests/test_auth.py), [выгрузки истории](../tests/test_history_export.py), [тестовый runtime](../tests/test_runtime_test_chat.py).
- **AC-03. Редактирование — пройден.** Две вкладки проверили получение аренды одним редактором и отказ второму. Сценарий потерянного ответа на сохранение проверил повтор и восстановление содержимого после перезагрузки. Серверная проверка проверила отозванную и истёкшую аренду и атомарную проверку ревизии. [Браузерный сценарий](../../frontend/scripts/smoke.mjs), [аренда и сохранение](../tests/test_drafts.py).
- **AC-04. Импорт и разметка — пройден.** CSV/JSON проходят проверку до применения. Неверный или устаревший файл сохраняет прежнюю ревизию. Проверены Unicode и диапазоны сущностей, межнаборный дубликат и ссылки на используемую сущность. [Интеграция импорта](../tests/test_imports.py), [валидация данных](../tests/test_dataset_validation.py), [тест координат браузера](../../frontend/scripts/test-offsets.mjs).
- **AC-05. Качество демонстрационных агентов — пройден.** У обоих агентов пять намерений, не менее десяти train и пяти test на намерение и по 20 неизвестных фраз. На ранее зафиксированном наборе intent macro F1 равен 0,948 и 0,978, exact-span F1 словарных сущностей равен 1,000 у обоих, доля отклонённых неизвестных запросов — 85% и 100%. Обе конфигурации прошли импорт, обучение до ready и тестовый чат. [Отчёт качества](../benchmarks/nlu/README.md), [регрессия сквозного запуска](../tests/test_demo_agents.py).
- **AC-06. Внешнее действие — подтверждено автоматическими проверками состава сценария.** Проверены сбор и ограничения параметра, mock HTTP-ответ, выбор только разрешённых полей, ошибка статуса, тайм-аут, невалидный или слишком большой ответ и неопределённый результат POST. Проверки клиента отклоняют приватные адреса и перенаправление. Chrome подтвердил сохранение интеграции, пути, маппинга и mock-ответа. [Сбор параметра](../tests/test_runtime_ask_slot.py), [мок интеграции](../tests/test_runtime_http_mock.py), [HTTP и обработка ошибок](../tests/test_integration_http_client.py), [сквозной маршрут версии](../tests/test_runtime_test_chat.py).
- **AC-07. Передача диалога — пройден.** Проверены выбранные входные параметры, явный результат возврата, сохранение остальных параметров, закрепление версии, цикл, глубина, граница организации и режим без предшествующего текста. [Handoff ядра](../tests/test_runtime_handoff.py), [handoff тестового чата](../tests/test_runtime_test_chat.py), [проверка графа](../tests/test_flow_validation.py).
- **AC-08. Публикация во время диалога — частично подтверждён.** Серверный сценарий закрепляет манифест A для уже начатого диалога и проверяет B для нового, смену целевого агента handoff, одновременные публикации и откат. Chrome подтвердил ответ внешнего API и виджета после публикации. Остаётся подтверждение непосредственно во время обучения новой версии того же агента. [Тест публикаций](../tests/test_release_routes.py), [браузерный сценарий](../../frontend/scripts/smoke.mjs).
- **AC-09. Виджет и внешний API — пройден.** На отдельном origin Chrome проверил реплики при ширине 320 px, управление клавиатурой и блокировку чужого сайта. Сервер проверил несовпадающий токен, отключение канала, отзыв ключа и извлечение секрета только при его создании. [Проверка виджета](../../frontend/scripts/widget-smoke.mjs), [публичные каналы](../tests/test_release_routes.py).
- **AC-10. Повтор и порядок ходов — частично подтверждён.** Проверены потерянный ответ, повтор без второй реплики, конфликт 409 с другим запросом, параллельные ходы и отсутствие повтора внешнего действия при восстановлении просроченной записи. Для полной приёмки нужен отдельный перезапуск API в момент внешнего POST. [Квитанции и конкуренция](../tests/test_runtime_test_chat.py), [журнал действий](../tests/test_action_ledger.py), [остановка приложения](../tests/test_runtime_shutdown.py).
- **AC-11. Приватность и история — пройден.** Тесты проверили отсутствие контрольного текста при ошибке NLU и тайм-ауте интеграции, очистку состояния по TTL и права выполнения удаления и выгрузки. Chrome подтвердил выгрузку, удаление по фильтрам, отзыв доступа к устаревшему файлу и поиск только при включённом тексте. [Приватность](../tests/test_runtime_privacy.py), [удаление истории](../tests/test_history_deletion.py), [выгрузка](../tests/test_history_export.py), [Chrome](../../frontend/scripts/smoke.mjs).
- **AC-12. Аналитика — пройден.** Ручная последовательность событий в интеграционных тестах проверяет отдельный fallback, технические ошибки, исключение тестовых ходов по умолчанию, повторы, handoff, границы периода и расчёт перцентилей. Chrome проверил сохранение метрик и событие аудита после удаления истории. [Аналитика runtime](../tests/test_runtime_analytics.py), [Chrome](../../frontend/scripts/smoke.mjs).
- **AC-13. Производительность — в работе.** Пробный прогон подтвердил работу измерений. Опубликованы два агента, оба десятисекундных профиля вернули по 20 ожидаемых ответов, отдельно прошли сохранения запросов размером около 1 и 10 МиБ. Полный профиль запущен в Linux ARM64, 10 vCPU, 7,8 ГиБ RAM. Соответствие NFR-01/02 на целевой конфигурации Linux x86-64, 8 vCPU, 16 ГиБ RAM остаётся непроверенным. [Команды нагрузки](../benchmarks/runtime/README.md).
- **AC-14. Эксплуатация и доступность — частично подтверждён.** Чистый production Compose прошёл запуск, HTTPS с тестовым CA, SMTP с STARTTLS и перезапуск. Восстановление на чистых томах вернуло опубликованный релиз и исключило ранее удалённые данные. Chrome проверил обе темы и размеры 320–390 px. Осталось отдельно свести покрытие ключевых экранов по пустым и ошибочным состояниям и клавиатуре. [Прогоны S14/S15](IMPLEMENTATION_STATUS.md), [операционные команды](OPERATIONS.md).

## Дополнительные нефункциональные условия

- **NFR-03. Большой сценарий.** Серверная граница 300 блоков и 600 связей проверена. Время открытия, drag и zoom нужно подтвердить в браузере. [Граница формата](../tests/test_flow_routes.py).
- **NFR-04. Восстановление работоспособности.** Проверены сохранение данных после перезапуска, обработка очереди после восстановления RabbitMQ, ручное подтверждение после фиксации результата, отсутствие двух ready-версий после повторной доставки и отдельный процесс миграций. [Рабочая очередь](../tests/test_jobs.py), [обучение](../tests/test_training_worker.py), [миграции](../tests/test_tenancy.py).
- **NFR-05/06. Изоляция и защита.** Серверные, браузерные и production-проверки покрыли RLS, CSRF, токены, CSP, HTTPS, непубликуемые порты базы и брокера, отказ для приватных адресов интеграций и недоступность артефактов без прав. Сводку по полному покрытию ролей см. в AC-02.
- **NFR-07. Резервная копия.** Подтверждены шифрование, ротация по сроку и чистое восстановление. Для RPO/RTO нужно зафиксировать измеренное время проверки и режим расписания на целевой установке. [Суточная копия и восстановление](OPERATIONS.md).
- **NFR-08. Отсутствие пользовательского текста в логах.** Контрольная строка проверена в PostgreSQL, логах, артефактах и наблюдаемом RabbitMQ при отключённом сохранении. Зашифрованное состояние удаляется по TTL. [Проверки AC-11](../tests/test_runtime_privacy.py).
