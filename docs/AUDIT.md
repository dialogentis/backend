## Проверки

- Ruff, форматирование и ty проходят.
- 13 автоматических тестов: валидация, версии, устаревание модели, параллельные сообщения, передача, лимит циклов, история, ошибки обучения, удаление связей, таймаут regex, раздача файлов и восстановление задач.
- В Chromium проверены защита несохранённых настроек и изоляция позднего ответа. Ошибок JavaScript не обнаружено.
- Реальная Rasa распознаёт запрос и передаёт его двум агентам с сохранением номера заказа в контексте.
- Измерение в текущем окружении: первая загрузка отдельной модели около 13 с, повторный анализ около 7 мс. Сквозной холодный запрос через двух агентов около 27 с; следующее сообщение того же диалога около 21 мс. Это отдельные измерения, не нагрузочный тест.

## Зависимости: нерешённое ограничение Rasa

pip-audit не нашёл известных уязвимостей в зафиксированных производственных зависимостях веб-сервера. В установленном окружении Rasa найдены 195 записей об известных уязвимостях в 16 пакетах. Полные машинные отчёты находятся в security/server-dependencies.json и security/rasa-dependencies.json. Наличие записи не доказывает достижимость уязвимости через этот API.

Rasa 3.6.21 жёстко ограничивает версии tensorflow (2.12.0), pydantic (<1.10.10), protobuf (<4.23.4), aiohttp (<3.10), sanic (<21.13), setuptools (<70.4), skops (0.9.0) и других библиотек. Исправленные версии ряда зависимостей не удовлетворяют этим ограничениям. Проверка обновления wheel также завершилась конфликтом packaging; исправленный filelock требует Python >=3.11, тогда как Rasa требует Python <3.11. Несовместимые версии принудительно не установлены.

Процесс Rasa используется локально через stdin/stdout; HTTP-сервер Rasa не запускается, загрузка сторонних моделей через API не предусмотрена. Это уменьшает поверхность доступа, но не устраняет уязвимости зависимостей. Для устранения этого ограничения нужен отдельный переход на поддерживаемый NLP-движок или совместимую поддерживаемую версию Rasa с повторной проверкой обучения. До такого перехода приложение предназначено для локальной учебной работы с доверенными конфигурациями.

## Границы проверки

Авторизация, публичный хостинг, распределённая очередь обучения, нагрузочное тестирование и оценка качества на независимом корпусе не реализованы. Они отсутствовали в согласованной первой версии. Приложение рассчитано на одного пользователя и один процесс Uvicorn. Холодная загрузка Rasa остаётся заметной; пул удерживает не более двух моделей.
