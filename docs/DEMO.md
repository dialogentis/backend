# Демонстрация Dialogentis

Сценарий рассчитан на отдельную установку. Для локальной демонстрации выполните [первый запуск](../README.md#первый-запуск). Настройте [подключение к языковой модели](../README.md#языковая-модель). Кабинет откроется на `http://localhost:18080`, письма появятся в Mailpit на `http://localhost:18025`.

## Подготовить и опубликовать агента

1. Зарегистрируйтесь, подтвердите почту по ссылке из Mailpit и войдите. Создайте пространство и агента «Поддержка заказов».
2. В каталоге backend создайте пакет агента.

   ```sh
   uv run --locked python -m benchmarks.nlu.demo order_support > /tmp/dialogentis-order-support.json
   ```

3. Откройте агента, нажмите «Начать редактирование» и перейдите на вкладку «Примеры». Выберите импорт JSON с заменой черновика. Просмотрите результат проверки, примените импорт и дождитесь сохранения.
4. На вкладке «Сценарий» проверьте связи. Точка входа ведёт к распознаванию намерения. Ветка «Статус заказа» отвечает клиенту, а неизвестный запрос идёт по отдельной ветке. Нажмите «Проверить сценарий».
5. На вкладке «Версии» нажмите «Подготовить версию». После готовности откройте версию. В тестовом чате отправьте «где сейчас мой заказ» и проверьте ответ и трассу.
6. Нажмите «Проверить публикацию». Проверьте результат и опубликуйте готовую версию.

## Проверить сайт и внешний API

1. На вкладке «Каналы» добавьте виджет и укажите точный origin отдельного сайта. Для локальной проверки можно использовать `http://127.0.0.1:8081`.
2. Скопируйте «Код вставки» в пустую HTML-страницу в отдельном каталоге и поднимите локальный сайт в этом каталоге.

   ```sh
   python3 -m http.server --bind 127.0.0.1 8081
   ```

3. Откройте страницу по указанному origin. Запустите чат и отправьте «где сейчас мой заказ».
4. На вкладке «Каналы» создайте отдельный API-ключ. Запустите второй диалог и отправьте то же сообщение. Проверьте реплику и сохраните `release_id` из ответа на создание диалога. [Примеры HTTP-запросов](../README.md#внешний-api).
5. В «Истории» найдите API- и виджет-диалоги по агенту и каналу. В «Аналитике» выберите текущий период и проверьте счётчики, намерения и время ответа для того же агента.

## Заменить версию и выполнить откат

1. В черновике измените текст в блоке ответа для статуса заказа. После сохранения подготовьте новую версию. Пока она готовится, начните публичный диалог и убедитесь, что работает первая публикация.
2. Протестируйте новый текст в тестовом чате второй версии и опубликуйте её. Новый публичный диалог получает новый текст, а его `release_id` отличается от прежнего.
3. В истории публикаций выберите «Откатить» у первой версии и укажите причину. В новом диалоге должен вернуться первоначальный ответ. В списке публикаций и в журнале аудита доступны сведения об откате.

Второго агента для демонстрации можно собрать по той же схеме из файла `education`. [Примеры и тестовые фразы](../benchmarks/nlu/README.md).
