# dialogentis — конструктор диалоговых агентов

Учебное веб-приложение для настройки нескольких русскоязычных агентов, обучения Rasa NLU, сценарного управления диалогом и диагностики. FastAPI и SQLite хранят конфигурации и историю; Rasa запускается в отдельном Python-окружении. Сценарии и передача между агентами исполняются сервером приложения, а не Rasa Core.

## Установка и запуск

Требуется установленный [uv](https://docs.astral.sh/uv/). Команды выполняются из каталога `backend`; `uv` установит нужные версии Python при необходимости. Сервер использует Python 3.14, а Rasa 3.6.21 — отдельное окружение Python 3.10 из-за ограничений самой Rasa. Оба набора зависимостей зафиксированы в соответствующих `uv.lock`.

```bash
uv sync --locked
uv sync --project rasa --locked
uv run python demo.py  # необязательно; только для пустой базы
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

По умолчанию приложение использует `rasa/.venv`; при необходимости путь к Python Rasa можно переопределить переменной `RASA_PYTHON`.

Откройте http://127.0.0.1:8000. Каталог `frontend` должен находиться рядом с `backend`; при другом расположении задайте `FRONTEND_DIR`. По умолчанию SQLite и обученные модели хранятся в `backend/data`; задайте `AGENT_DATA_DIR` для другого расположения. Используйте один процесс Uvicorn: фоновое обучение управляется текущим процессом.

## Работа

1. Создайте агента или загрузите примеры командой `demo.py`. Укажите минимум два намерения с двумя или более примерами на каждое; имена намерений и сущностей задаются латиницей.
2. При необходимости задайте сущности регулярными выражениями Python, правила для пар «состояние — намерение», ответы и целевого агента. Состояние нового диалога — `start`. Сохраните изменения.
3. На вкладке «Обучение» запустите Rasa. Дождитесь окончания обучения; при ошибке откройте сообщение на этой вкладке. Последняя успешно обученная модель продолжает работать при неудачном переобучении и при изменении конфигурации.
4. На вкладке «Тестовый диалог» отправьте сообщение. Диагностика показывает намерение, оценку уверенности, сущности, состояние и выбранное действие. Сессия и история сохраняются в SQLite, а её идентификатор — в браузере. «Новый диалог» начинает новую сессию.
5. Для демонстрации передачи обучите обоих демонстрационных агентов, откройте учебного помощника и отправьте «где мой заказ 1234». После передачи последующие сообщения поступают целевому агенту. Сущности сохраняются в контексте сеанса. Ограничение — шесть обработок одного сообщения, чтобы прервать циклы.

Низкая уверенность и отсутствие подходящего правила приводят к ответу по умолчанию. Извлечение сущностей работает по регулярным выражениям; автоматическая разметка и обучение сущностей по примерам не реализованы. Сценарии представляют собой правила переходов между именованными состояниями; внешние действия, управление пользователями и внешние каналы не предусмотрены. При перезапуске сервера незавершённое обучение помечается ошибкой.

## Проверка

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
uv run python -m unittest discover -s tests -v
```

Тесты проверяют API, сохранение конфигурации, устаревание модели, передачу и состояние диалога, историю, циклы и сохранение модели при ошибке обучения. Для полноценной проверки Rasa отдельно обучите демонстрационных агентов через интерфейс.

## Результат аудита

См. [отчёт](docs/AUDIT.md): исправления, проверки и оставшиеся ограничения зависимостей Rasa. Для локальной работы используйте один процесс сервера и адрес 127.0.0.1. Пул распознавания удерживает до двух моделей; первая загрузка остаётся медленной, повторные запросы используют загруженную модель. Поиск сущностей ограничен таймаутом. Интерфейс сохраняет изменения перед обучением и проверяет версию ресурса, чтобы обнаруживать конфликт правок из другого окна.
